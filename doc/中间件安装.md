## 四、Kafka

### 安装信息

| 项目 | 信息 |
|------|------|
| 版本 | Apache Kafka 3.9.2 (Scala 2.13) |
| 安装路径 | `C:\tools\kafka\kafka_2.13-3.9.2` |
| 配置文件 | `C:\tools\kafka\kafka_2.13-3.9.2\config\kraft\server.properties` |
| 运行模式 | KRaft（无需 ZooKeeper） |
| Broker 端口 | 9092 |
| Controller 端口 | 9093 |
| 数据目录 | `C:/tools/kafka/kafka_2.13-3.9.2/kraft-combined-logs` |
| 环境变量 | `KAFKA_HOME=C:\tools\kafka\kafka_2.13-3.9.2` |
| UUID | `nsZGfl1sTseV-kfj4ugL2w` |
| 启动脚本 | `C:\tools\kafka\kafka_2.13-3.9.2\start-kafka.bat` |
| 停止脚本 | `C:\tools\kafka\kafka_2.13-3.9.2\stop-kafka.bat` |

### 一键安装

```powershell
# 1. 下载（华为云镜像）
Invoke-WebRequest -Uri "https://repo.huaweicloud.com/apache/kafka/3.9.2/kafka_2.13-3.9.2.tgz" -OutFile "C:\tools\kafka\kafka_2.13-3.9.2.tgz"

# 2. 解压
New-Item -Path "C:\tools\kafka" -ItemType Directory -Force
tar -xzf "C:\tools\kafka\kafka_2.13-3.9.2.tgz" -C "C:\tools\kafka"

# 3. 修改配置：将 log.dirs 改为 Windows 路径
(Get-Content "C:\tools\kafka\kafka_2.13-3.9.2\config\kraft\server.properties") -replace 'log.dirs=/tmp/kraft-combined-logs', 'log.dirs=C:/tools/kafka/kafka_2.13-3.9.2/kraft-combined-logs' | Set-Content "C:\tools\kafka\kafka_2.13-3.9.2\config\kraft\server.properties"

# 4. 格式化 KRaft 存储（生成 UUID 并格式化）
$uuid = java -cp "C:\tools\kafka\kafka_2.13-3.9.2\libs\*" kafka.tools.StorageTool random-uuid
java -cp "C:\tools\kafka\kafka_2.13-3.9.2\libs\*" kafka.tools.StorageTool format -t $uuid -c "C:\tools\kafka\kafka_2.13-3.9.2\config\kraft\server.properties"
```

### 常用操作

```bash
# 启动（前台运行，可看实时日志）
C:\tools\kafka\kafka_2.13-3.9.2\start-kafka.bat

# 启动（后台运行，推荐）
Start-Process -FilePath "C:\tools\kafka\kafka_2.13-3.9.2\start-kafka.bat" -WindowStyle Hidden

# 停止
C:\tools\kafka\kafka_2.13-3.9.2\stop-kafka.bat

# 或手动查找进程 ID 后停止
netstat -aon | findstr ":9092.*LISTENING"
taskkill /PID <进程ID> /F

# 创建 Topic
java -cp "C:\tools\kafka\kafka_2.13-3.9.2\libs\*" kafka.admin.TopicCommand --create --topic test --bootstrap-server localhost:9092

# 查看 Topic 列表
java -cp "C:\tools\kafka\kafka_2.13-3.9.2\libs\*" kafka.admin.TopicCommand --list --bootstrap-server localhost:9092
```

### Spring Boot 连接配置

| 配置项 | 值 |
|--------|-----|
| 依赖 | `spring-kafka` |
| `spring.kafka.bootstrap-servers` | `localhost:9092` |
| `spring.kafka.consumer.group-id` | `test-group` |
| `spring.kafka.producer.key-serializer` | `org.apache.kafka.common.serialization.StringSerializer` |
| `spring.kafka.consumer.value-deserializer` | `org.apache.kafka.common.serialization.StringDeserializer` |

> **注意：**
> - Windows 下 Kafka 自带的 `.bat` 脚本因 classpath 过长会报"输入行太长"错误，因此使用自定义 `start-kafka.bat` 通过 `java -cp` 方式直接调用。
> - PowerShell 下直接执行 `java -D` 参数会被误解析，必须通过 `.bat` 脚本或 `Start-Process` 间接启动。
> - 首次启动前必须先格式化 KRaft 存储目录（见一键安装第 4 步），否则会报 `org.apache.kafka.common.errors.InconsistentClusterIdException`。

## 五、一键启停

### 启动全部服务

```bash
# 1. MySQL（Windows 服务）
net start MySQL

# 2. Redis（后台运行）
start /B redis-server

# 3. Kafka（KRaft 模式，后台运行）
Start-Process -FilePath "C:\tools\kafka\kafka_2.13-3.9.2\start-kafka.bat" -WindowStyle Hidden
```

### 停止全部服务

```bash
# 1. MySQL
net stop MySQL

# 2. Redis
taskkill /IM redis-server.exe /F

# 3. Kafka
C:\tools\kafka\kafka_2.13-3.9.2\stop-kafka.bat
```

### 验证服务状态

```bash
netstat -aon | findstr "3306 6379 9092"

# 期望输出：
#   3306  LISTENING  -> MySQL
#   6379  LISTENING  -> Redis
#   9092  LISTENING  -> Kafka
```
