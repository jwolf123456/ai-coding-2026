# 中间件安装与运维手册

本项目依赖以下中间件服务：Nacos、MySQL、Redis、Kafka。

| 服务    | 版本     | 端口          | 运行方式       |
|-------|--------|-------------|------------|
| Nacos | 3.3.0  | 8080 / 8848 | 独立部署       |
| MySQL | 8.0.44 | 3306        | Windows 服务 |
| Redis | 8.6.2  | 6379        | 后台进程       |
| Kafka | 3.9.2  | 9092        | KRaft 模式   |

## 一、Nacos

| 项目          | 信息                                                             |
|-------------|----------------------------------------------------------------|
| 版本          | Nacos 3.3.0                                                    |
| 安装路径        | `C:\Users\Administrator\ai-infra\nacos\standalone\nacos-3.3.0` |
| HTTP API 端口 | 8080（3.x 新增，REST API 和控制台）                                     |

| Java 版本要求   | JDK 17+（当前环境 JDK 21）                                           |

### 一键安装

```powershell
# 1. 下载
Invoke-WebRequest -Uri "https://github.com/alibaba/nacos/releases/download/3.3.0/nacos-server-3.3.0.zip" -OutFile "C:\Users\Administrator\ai-infra\nacos\standalone\nacos-server-3.3.0.zip" -UseBasicParsing

# 2. 解压
New-Item -Path "C:\Users\Administrator\ai-infra\nacos\standalone" -ItemType Directory -Force
Expand-Archive -Path "C:\Users\Administrator\ai-infra\nacos\standalone\nacos-server-3.3.0.zip" -DestinationPath "C:\Users\Administrator\ai-infra\nacos\standalone" -Force
```

### 鉴权配置

Nacos 3.x **默认开启鉴权**，启动前必须配置以下三项（`conf/application.properties`）：

```properties
# 鉴权开关（默认已开启，无需修改）
nacos.core.auth.enabled=true
nacos.core.auth.admin.enabled=true
nacos.core.auth.console.enabled=true
# 服务端内部通信身份标识（微服务注册/发现时使用）
nacos.core.auth.server.identity.key=nacos_identity_1793539687
nacos.core.auth.server.identity.value=x4V3G1/O8wCHFPW5
# JWT 签名密钥（Base64 编码，长度 >= 32）
# 注意：nacos.plugin.auth.nacos.token.secret.key 优先级高于 legacy key
nacos.plugin.auth.nacos.token.secret.key=V8Fk23qoq/Yf7HRABxSlK4oxOtgvFu9vkYZ/hpHuazE=
```

> ⚠️ **重要：** `nacos.plugin.auth.nacos.token.secret.key` 不能为空！Nacos 3.x 优先读取此 key，若为空会报
`Required config missing: token.secret.key` 启动失败。解压后默认此值为空，必须手动填入。

### 启动与停止

```bash
# 启动（standalone 单机模式）
cd C:\Users\Administrator\ai-infra\nacos\standalone\nacos-3.3.0
.\bin\startup.cmd -m standalone

# 停止
.\bin\shutdown.cmd

# 或按端口查找进程后停止
$pid = (Get-NetTCPConnection -LocalPort 8848 -State Listen).OwningProcess
Stop-Process -Id $pid -Force
```

### Nacos 3.x 与 2.x 端口差异

| 端口   | Nacos 2.x             | Nacos 3.x      | 用途                 |
|------|-----------------------|----------------|--------------------|
| 8848 | HTTP API + 控制台 + gRPC | gRPC（客户端通信）    | SDK 客户端连接          |
| 8080 | 不使用                   | HTTP API + 控制台 | REST API 和 Web 控制台 |
| 7848 | Raft 内部通信             | Raft 内部通信      | 集群内部               |

> 官网：https://nacos.io/

## 四、Kafka

### 安装信息

| 项目 | 信息 |
|------|------|
| 版本 | Apache Kafka 3.9.2 (Scala 2.13) |
| 安装路径 | `C:\tools\kafka\kafka_2.13-3.9.2` |
| 配置文件 | `C:\tools\kafka\kafka_2.13-3.9.2\config\kraft\server.properties` |
| 运行模式 | KRaft（无需 ZooKeeper） |
| Broker 端口 | 9092 |
| Controller 端口 | 9093 |
| 数据目录 | `C:/tools/kafka/kafka_2.13-3.9.2/kraft-combined-logs` |
| 环境变量 | `KAFKA_HOME=C:\tools\kafka\kafka_2.13-3.9.2` |
| UUID | `nsZGfl1sTseV-kfj4ugL2w` |
| 启动脚本 | `C:\tools\kafka\kafka_2.13-3.9.2\start-kafka.bat` |
| 停止脚本 | `C:\tools\kafka\kafka_2.13-3.9.2\stop-kafka.bat` |

### 一键安装

```powershell
# 1. 下载（华为云镜像）
Invoke-WebRequest -Uri "https://repo.huaweicloud.com/apache/kafka/3.9.2/kafka_2.13-3.9.2.tgz" -OutFile "C:\tools\kafka\kafka_2.13-3.9.2.tgz"

# 2. 解压
New-Item -Path "C:\tools\kafka" -ItemType Directory -Force
tar -xzf "C:\tools\kafka\kafka_2.13-3.9.2.tgz" -C "C:\tools\kafka"

# 3. 修改配置：将 log.dirs 改为 Windows 路径
(Get-Content "C:\tools\kafka\kafka_2.13-3.9.2\config\kraft\server.properties") -replace 'log.dirs=/tmp/kraft-combined-logs', 'log.dirs=C:/tools/kafka/kafka_2.13-3.9.2/kraft-combined-logs' | Set-Content "C:\tools\kafka\kafka_2.13-3.9.2\config\kraft\server.properties"

# 4. 格式化 KRaft 存储（生成 UUID 并格式化）
$uuid = java -cp "C:\tools\kafka\kafka_2.13-3.9.2\libs\*" kafka.tools.StorageTool random-uuid
java -cp "C:\tools\kafka\kafka_2.13-3.9.2\libs\*" kafka.tools.StorageTool format -t $uuid -c "C:\tools\kafka\kafka_2.13-3.9.2\config\kraft\server.properties"
```

### 常用操作

```bash
# 启动（前台运行，可看实时日志）
C:\tools\kafka\kafka_2.13-3.9.2\start-kafka.bat

# 启动（后台运行，推荐）
Start-Process -FilePath "C:\tools\kafka\kafka_2.13-3.9.2\start-kafka.bat" -WindowStyle Hidden

# 停止
C:\tools\kafka\kafka_2.13-3.9.2\stop-kafka.bat

# 或手动查找进程 ID 后停止
netstat -aon | findstr ":9092.*LISTENING"
taskkill /PID <进程ID> /F

# 创建 Topic
java -cp "C:\tools\kafka\kafka_2.13-3.9.2\libs\*" kafka.admin.TopicCommand --create --topic test --bootstrap-server localhost:9092

# 查看 Topic 列表
java -cp "C:\tools\kafka\kafka_2.13-3.9.2\libs\*" kafka.admin.TopicCommand --list --bootstrap-server localhost:9092
```

### Spring Boot 连接配置

| 配置项 | 值 |
|--------|-----|
| 依赖 | `spring-kafka` |
| `spring.kafka.bootstrap-servers` | `localhost:9092` |
| `spring.kafka.consumer.group-id` | `test-group` |
| `spring.kafka.producer.key-serializer` | `org.apache.kafka.common.serialization.StringSerializer` |
| `spring.kafka.consumer.value-deserializer` | `org.apache.kafka.common.serialization.StringDeserializer` |

> **注意：**
> - Windows 下 Kafka 自带的 `.bat` 脚本因 classpath 过长会报"输入行太长"错误，因此使用自定义 `start-kafka.bat` 通过 `java -cp` 方式直接调用。
> - PowerShell 下直接执行 `java -D` 参数会被误解析，必须通过 `.bat` 脚本或 `Start-Process` 间接启动。
> - 首次启动前必须先格式化 KRaft 存储目录（见一键安装第 4 步），否则会报 `org.apache.kafka.common.errors.InconsistentClusterIdException`。

## 五、一键启停

### 启动全部服务

```bash
# 1. MySQL（Windows 服务）
net start MySQL

# 2. Redis（后台运行）
Start-Process -FilePath "redis-server" -WindowStyle Hidden

# 3. Kafka（KRaft 模式，后台运行）
Start-Process -FilePath "C:\tools\kafka\kafka_2.13-3.9.2\start-kafka.bat" -WindowStyle Hidden

# 4. Nacos 3.3.0（Standalone 模式）
Start-Process -FilePath "C:\Users\Administrator\ai-infra\nacos\standalone\nacos-3.3.0\bin\startup.cmd" -ArgumentList "-m standalone" -WindowStyle Minimized
```

### 停止全部服务

```bash
# 1. MySQL
net stop MySQL

# 2. Redis
taskkill /IM redis-server.exe /F

# 3. Kafka
C:\tools\kafka\kafka_2.13-3.9.2\stop-kafka.bat

# 4. Nacos
C:\Users\Administrator\ai-infra\nacos\standalone\nacos-3.3.0\bin\shutdown.cmd
```

### 验证服务状态

```bash
netstat -aon | findstr "3306 6379 9092 8080 8848"

# 期望输出：
#   3306  LISTENING  -> MySQL
#   6379  LISTENING  -> Redis
#   9092  LISTENING  -> Kafka
#   8080  LISTENING  -> Nacos HTTP API / 控制台
#   8848  LISTENING  -> Nacos gRPC
```
